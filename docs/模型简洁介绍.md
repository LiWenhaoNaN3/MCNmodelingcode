# 模型简洁介绍（定位模型 v2）

> 本文把「物理模型 + 数值模拟 + 统计算法」压成一份可独立阅读的说明，附**变量对照表**与**数据来源**。
> 对应代码：`src/config.py`（参数）、`src/data.py`（数据/流场/地形）、`src/locate.py`（集合预报）、
> `src/posterior.py`（后验统计）、`src/figs_p2.py` 与 `src/figs_field.py`（图件）。
> 一句话：**把「失联后可能去哪」拆成 5 种事故情形，每种用一条运动方程描述，再让 2 万个"不同假设下的潜水器"各跑 4 天，落点密集处就是重点搜索区。**

---

## 1. 建模思路（三句话）

1. **分情形**：失联不等于沉底。按设备状态与压载情况分 5 种情形（部分再分 2 支），每种给一个先验概率。
2. **算运动**：每种情形下，潜水器受浮力、重力、水动力阻力、海流、海底摩擦控制，用方程描述其三维轨迹。
3. **带不确定性**：把查不到的 7 个物理量当作随机变量（给定范围），用两万组随机组合各跑一遍，得到位置的概率分布。

## 3. 物理模型

### 3.1 五个事故情形

| 代号 | 含义 | 结果 | 先验 |
|---|---|---|---|
| S0 | 失联但系统正常，自动上浮成功 | 水面 | 0.15 |
| S1 | 失去推进 + 失联，近中性浮力 | 水柱定深漂流 | 0.55 |
| S2 | 断电：抛载成功(→水面) / 失败(→无动力漂流) | 水面 / 水柱 | 0.15 |
| S3 | 耐压壳进水，快速下沉 | 沉底 → 滑移 | 0.10 |
| S4 | 压载舱进水，中速下沉 | 沉底 → 滑移 | 0.05 |

### 3.2 海水密度（EOS-80）

```
ρ₀(T,S)  = 一个大气压下的海水密度          [kg/m³]
K(T,S,p) = K₀ + p·K₁ + p²·K₂               [bar]
ρ(T,S,p) = ρ₀ / (1 − p/K)                   [kg/m³]
```

为什么用**现场密度**：耐压壳体积近似不变，浮力取决于当地实际密度。
若用扣掉压力的"位势密度"，本站点会偏差 1.3（300 m）–4.5（1000 m）kg/m³，比 Δρ 本身大一个量级。

### 3.3 垂向运动

```
m* · dw/dt = F − k · w · |w|
F = (m − ρ(z)·V)·g            （净垂向力，向下为正）
k = ½·ρ(z)·C_D·A              （阻力组合系数）
m* = m + 0.5·ρ(z)·V           （有效质量）
```

**终端速度**（匀速时 w 不再变）：

```
w_t = sign(Δρ) · sqrt( 2·|Δρ|·V·g / (ρ·C_D·A) )
```

**解析解**（力与密度在一步内视为常数）：

```
w(t) = w_t · tanh( atanh(w₀/w_t) + t/τ )          τ = m*/(k·|w_t|)
z(t) = z₀ + w_t·τ·[ ln cosh(atanh(w₀/w_t)+t/τ) − ln cosh(atanh(w₀/w_t)) ]
```

用解析解而不用差分，因为大 Δρ 时松弛时间 τ 可小到 5–6 秒，普通显式差分（步长 10 s）会发散；
解析解对任意步长无条件稳定。实际计算时每步用当前 z 重新算 ρ、F、k、w_t、τ。

### 3.4 水平运动（准稳态近似）

水平方向只有阻力，相对水的速度以时间常数衰减：

```
τ_h = m* / (k·|v_rel|) ≈ 16500 / (1358×0.05) ≈ 243 s ≈ 4 min
```

所以 4 分钟后潜水器基本与海水同速，几小时尺度上可直接按流场平流：

```
dx/dt = u(x,y,z,t) + b_x + ε_x + ξ_x
dy/dt = v(x,y,z,t) + b_y + ε_y + ξ_y
```

被忽略的惯性位移量级 ≈ |v_rel|·τ_h ≈ 12 m，相对公里级漂移可忽略。

### 3.5 四维流场与插值

数据形如 `U[i,j,k,n]`：`i,j` 经纬格点、`k` 深度层、`n` 时间。任意位置插值为
**空间双线性 + 深度线性 + 时间线性**：

```
U(x,y,z,t) = Σ_{a,b,c,d ∈ {0,1}} α_a·β_b·γ_c·δ_d · U_{i+a, j+b, k+c, n+d}
```

其中 `α_a, β_b` 为经/纬向权重，`γ_c` 为深度权重，`δ_d` 为时间权重，各自两两和为 1。
数据：20×17 网格、6 层（0/100/300/500/700/1000 m）、17 个时刻（6 h 间隔，0–96 h）。

### 3.6 流场误差（三项）

```
① 系统性偏差:   b_x, b_y ~ N(0, σ_b²),  σ_b = 0.02 m/s, 全程不变
② 时变误差:     dε = −(1/τ_ε)·ε·dt + σ_ε·√(2/τ_ε)·dW
   离散形式:    ε_{n+1} = a·ε_n + σ_ε·√(1−a²)·ξ,  a = exp(−Δt/τ_ε)
③ 次网格湍流:   Δx_湍流 = √(2·K·Δt)·ξ
```

三项在 96 h 造成的位移量级：①6.9 km ②2.5 km ③1.2 km → 合计约 7.4 km/方向。

### 3.7 海底接触与滑移

触底判据 `z ≥ h(x,y)`。之后**每一步用当前位置的坡度重新判断**：

```
若 tan θ(x,y) ≤ μ_s → 停住（吸收态）
若 tan θ(x,y) > μ_s → 沿下坡方向 ∇h 前进 ds = 20 m，再判一次
（上限 4000 步 = 80 km，超出地形范围即停）
```

本模型里坡度是**场**而不是一个数：每一步都重算（图 G2b）；
沿下坡方向的坡度剖面为 21.2°（起点）→ 25.2°（600 m）→ 18.0°（1400 m）→ 13.6°（1600 m）。
**注意数据尺度局限**：ETOPO 格距约 464 m，而艇只有 4.5 m，小尺度起伏无法解析，
所以"滑/不滑"本质上是概率性判断。

### 3.8 三类吸收态

| 判据 | 状态 | 之后 |
|---|---|---|
| `z ≥ h(x,y)` | 沉底 | 位置锁定（经滑移后） |
| `z ≤ 0` | 水面 | 水平漂移 + 风致漂移 v_风 = α_风·U_风 |
| `|ρ(z) − ρ_b| < 0.005` | 中性浮力 | 垂向锁定，水平跟随流场 |

### 3.9 失事位置是"一片海域的随机点"

失事位置**不是固定点**，而是在 4 km × 4 km 的海域内随机（只取水深 ≤ 额定潜深 1000 m 的可下潜区域），
再叠加 100 m 的定位误差。这条先验的意义：

- 不同失事点的**当地海底深度与坡度不同**（本区域 386–1000 m、3.4°–24.7°），
  "沉底后滑不滑、滑多深"因此不同；
- 不同失事点的**流场不同**，漂移轨迹不同；
- 同时施加物理约束：失事深度 `z₀` 不能超过当地海底（`z₀ ≤ h(x₀,y₀) − 20 m`）。

### 3.10 压溃：事后判定

模拟**不判压溃**，只得到终点位置与终点水深；
统计阶段给出"若假定压溃深度为 D_c，则压溃概率 = 终点水深 > D_c 的比例"。
好处：压溃深度从模型输入变成可扫参数，评审可自行取安全系数。

## 4. 数值模拟

### 4.1 混合先验采样

- **情形**：按精确比例分配（15%/55%/15%/10%/5%）后随机打乱；
- **连续参数**：`z₀`（三角分布）与 `μ_s`（均匀分布）用**拉丁超立方**分层抽样
  （把 [0,1] 分成 N 段各取一点再打乱，比纯随机覆盖更均匀）；其余按各自分布抽；
- 每个样本独立计算 `V, A, R, ρ_b, m*, b, ε₀, 风向风速`。

| 参数 | 分布 |
|---|---|
| `z₀` | 三角(300, 450, 600) m，且截断到 ≤ 当地海底深度 − 20 m |
| **失事位置** | 4 km × 4 km 矩形内均匀分布（仅取水深 ≤ 1000 m 的区域），再叠加 100 m 定位误差 |
| `Δρ`（S1） | N(0, 0.05²)，截断 ±0.30 |
| `Δρ`（S2 沉底支） | U(0.02, 0.50) |
| `Δρ`（S3） | U(20, 60) |
| `Δρ`（S4） | U(5, 20) |
| `μ_s` | U(0.20, 0.50) |
| `C_D` | N(0.45, 0.05²) 截断 [0.30, 0.60] |
| `σ₀` | 100 m（双向独立） |
| `b_x, b_y` | N(0, 0.02²) |
| `ε` 初值 | N(0, 0.03²) |
| `U_风, φ_风` | U(4,12) m/s、U(0,2π) |

### 4.2 两段式时间推进

```
第一阶段 (0 → 2 h)：Δt = 10 s，720 步
   每步：① 垂向解析推进 → 判吸收态（触底立刻滑移）
        ② 水平推进（流场 + 偏差 + OU + 随机游走）
        ③ 在 t = 1, 2 h 记快照
第二阶段 (2 → 96 h)：Δt = 900 s，376 步
   每步：① 罕见未停稳样本继续垂向解析推进
        ② 水平推进；③ 在 t = 4,8,12,24,36,48,72,96 h 记快照
```

原因：沉降/触底只需几分钟到一小时（要算准落地时刻 → 小步长）；
之后只剩水平漂移，流场变化是小时级 → 大步长。

### 4.3 状态机

```
状态 0「运动中」 ──触底──→ 状态 3「沉底」(位置锁定)
                ├─到水面─→ 状态 2「水面」(水平漂 + 风致漂移)
                └─中性浮力→ 状态 1「悬停」(垂向锁定 + 水平跟随流场)
```

### 4.4 伪代码

```
for i in 1..N:                       # 2 万个平行世界
    抽 情形、z₀、Δρ、μ_s、C_D、σ₀、b、ε、风
    算 V, A, R, ρ_b, m*
    x,y ~ N(0,σ₀);  z ← z₀;  w ← 0
    水平速度 ← 准稳态（跟随流场）

阶段一: for k in 1..720:  Δt=10 s
    对"运动中"样本: 用解析解推进 (w,z)
        若 z ≥ h(x,y): 状态←沉底, 立即做滑移(逐步重算坡度)
        若 z ≤ 0:     状态←水面
        若 |ρ−ρ_b|<0.005: 状态←悬停
    对所有未沉底样本:  x += (u_流 + b_x + ε_x)·Δt + √(2KΔt)·ξ
                     y += (v_流 + b_y + ε_y)·Δt + √(2KΔt)·ξ
    记录快照

阶段二: for k in 1..376:  Δt=900 s
    垂向（仅未停稳者）+ 水平漂移 + 快照

统计:  概率网格 → A50/A95 → 分支概率 → 事后压溃曲线
```

| 项 | 值 |

## 5. 统计算法

### 5.1 概率网格

平面划成 1 km × 1 km 网格（±40 km，80×80 格）：

```
p_jk = n_jk / N_条件          n_jk = 落在格 (j,k) 的样本数
```

再做两次 3×3 邻域平滑（抑制抽样噪声）：

```
p_jk ← 0.5·p_jk + 0.125·(上+下+左+右)
```

### 5.2 包含域 A50 / A95

把 6400 个格按概率从大到小排序、累加，直到累计概率达到 50% / 95%，
已加入格数 × 1 km² 即为 `A50` / `A95`（"有 50%/95% 把握它在这么大的区域里"）。

### 5.3 事后压溃曲线

对假定压溃深度 `D_c` 的网格（900–2100 m，步长 50 m），统计
`沉底样本中终点水深 > D_c` 的比例，得到"压溃概率 vs D_c"曲线。

### 5.4 收敛判据

随机二分：把两万样本随机分成两半各算 A95，相对差 < 5% 判合格。
当前 t = 24 h 的两半为 89 / 86 km²，相对差 3.4%。

## 8. 已知局限

1. **海流误差结构简化**：只有单套再分析数据（可用 Copernicus MEDSEA 4–5 km / 141 层做交叉验证，但需账号）。
2. **密度只用站点单根剖面**：未用四维温盐场；不过失事海域 4 km 仍落在同一个 HYCOM 9 km 网格附近，误差有限。
3. **失事海域形状简化**：用 4 km × 4 km 矩形均匀分布代替"实际潜点/航线"（可改为沿航线的线状先验，见待确认项）。
4. **地形尺度不匹配**：ETOPO 464 m 网格 vs 4.5 m 艇壳，小尺度粗糙度不可解析 → 滑移判据是概率性的。
5. **压载状态未知**：`Δρ` 只能给范围，无法从公开数据确定。
6. **水面风场未用实测**：仅按 4–12 m/s 随机抽样。
7. **不含潮汐**：HYCOM 为环流产品，潮流分量未计入（本海区潮流约 0.1 m/s 量级）。
